简单来说，**内核（Kernel）** 是操作系统的“大脑”和“最核心部分”。它是硬件（如 CPU、内存、硬盘）与软件（如 浏览器、游戏、微信）之间的**翻译官**和**管理者**。
<hr id="ItCT0" class="ne-hr">
## 1. 内核的核心职能

如果把计算机比作一家餐厅，软件是“顾客”，硬件是“后厨设备”，那么**内核就是“主厨兼经理”**。


- **进程管理（CPU 调度）**：内核决定哪个软件可以使用 CPU，以及使用多长时间，确保系统不会因为某个程序卡死而崩溃。
- **内存管理**：内核为每个运行的程序划定“地盘”，防止软件 A 恶意或无意地修改软件 B 的数据。
- **设备驱动**：内核是硬件的说明书。它让操作系统能认得并操控你的显卡、键盘、网卡等。
- **文件系统管理**：负责在硬盘上组织、读写和存储数据。
- **系统调用 (System Calls)**：这是软件向内核申请资源的“窗口”。比如你想保存一个文件，软件会发起一个系统调用，请内核去操作硬盘。

## 3. 如何查看内核版本？

了解自己的内核版本，对于安装驱动或修复安全漏洞（如“脏牛”漏洞）至关重要。

### 在 Linux 上 (Ubuntu, CentOS 等)

打开终端，输入：

```
uname -r
```

*输出示例：**5.15.0-101-generic**。其中 **5** 是主版本号，**15** 是次版本号。*

### 在 Windows 上


- 按下 Win + R 键，输入 cmd。
- 输入：

```
ver
```

*或者搜索“系统信息”查看内核版本（如 Windows NT 10.0）。*

### 在 macOS 上

打开终端，输入：

```
uname -v
```

## 4. 为什么要关心内核？


- **性能提升**：新内核通常对多核处理器和 SSD 优化更好。
- **硬件兼容性**：如果你买了一块 2026 年最新的显卡，但还在用 2020 年的内核，系统可能根本不认它。
- **安全性**：内核是系统的最后一道防线。内核级的漏洞意味着攻击者可以接管整台机器。
