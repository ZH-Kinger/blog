**计算机网络**就是利用通信线路和设备，将分布在不同地点的、具有独立功能的计算机系统连接起来，通过网络软件（网络协议、操作系统等）实现**资源共享**和**信息传递**的系统。

如果把计算机比作孤岛，计算机网络就是连接这些孤岛的桥梁、航线和海底电缆。
<hr id="Vpjtn" class="ne-hr">
## 1. 计算机网络的基本组成

一个完整的网络通常由以下三个部分构成：


- **硬件**：包括终端设备（手机、电脑）、传输介质（网线、光纤、Wi-Fi无线电波）和中间设备（路由器、交换机）。
- **软件**：主要指网络操作系统和各种应用程序（如浏览器、微信）。
- **协议 (Protocol)**：这是网络的“语言”。就像交通规则一样，规定了数据如何打包、如何寻址、如何纠错（如 TCP/IP 协议）。
<hr id="UjGXo" class="ne-hr">
## 2. 网络的分类（按地理范围）

根据覆盖范围的大小，我们通常将网络分为：


- **局域网 (LAN)**：范围最小，通常在一个办公楼、学校或家里。速度极快。
- **城域网 (MAN)**：覆盖一个城市，通常由电信运营商建立。
- **广域网 (WAN)**：跨越国家、州甚至全球。**互联网 (Internet)** 就是全球最大的广域网。
<hr id="vP6AF" class="ne-hr">

## 4. 计算机网络的核心功能


- **数据通信**：发送文字、图片、视频、语音。
- **资源共享**：打印机共享、服务器上的数据库共享、云计算能力共享。
- **分布式处理**：将一个巨大的计算任务分给成千上万台计算机共同完成

## web是什么？

简单来说，**Web**（全称 World Wide Web，万维网）是运行在互联网（Internet）之上的一种**信息系统**。

很多人容易混淆 Web 和互联网，其实它们的关系是：**互联网是“路”（底层物理基础），而 Web 是路上跑的“车”（一种应用服务）。**
<hr id="JtrHf" class="ne-hr">
### 1. Web 的核心三大支柱

Web 之所以能运行，依靠的是蒂姆·伯纳斯-李（Tim Berners-Lee）最初定义的三个核心技术：


- **HTML (超文本标记语言)**：Web 的**内容**。它决定了网页上哪里是标题，哪里是图片，哪里是链接。
- **HTTP (超文本传输协议)**：Web 的**语言**。它规定了浏览器如何向服务器请求网页，服务器又如何把网页传回来。
- **URL (统一资源定位符)**：Web 的**地址**。就像 https://www.google.com，它让全世界的每一个网页都有唯一的“门牌号”。

### 3. Web 的工作原理（当你输入网址时发生了什么？）

这是一个经典的“请求-响应”过程：


- **解析域名**：你的浏览器通过 **DNS** 把 google.com 变成 IP 地址。
- **建立连接**：浏览器和服务器通过 **TCP 协议** 握手，确保通道畅通。
- **发送请求**：浏览器发出一个 **HTTP GET** 请求：“你好，我要看首页。”
- **服务器响应**：服务器找到对应的 HTML、CSS、JavaScript 文件并传回给浏览器。
- **渲染页面**：浏览器解析这些代码，把它变成你看到的精美画面。
<hr id="CYBFr" class="ne-hr">
### 4. Web 开发的两个视角

如果你想了解如何“做”一个 Web，通常分为两个领域：


- **前端 (Frontend)**：用户看得见、摸得着的部分。主要技术是 **HTML、CSS、JavaScript**。
- **后端 (Backend)**：运行在服务器上，处理数据和逻辑的部分。常用语言包括 **Python、Java、Go、Node.js**，以及**数据库**。

# 网络协议（protocol）

协议是干什么的？为什么需要协议？

协议是让所有网络设备+计算机+手机+软件之间的通信，交流的

协议是软件 --》tcp/ip协议 --》用c语言写的

在网络世界里，连接两台电脑仅仅有物理网线是不够的。如果一台电脑发送的是中文编码，另一台只识别英文编码，或者一台发送速度极快，另一台接收极慢，通信就会失败。协议的存在，就是为了消除这些障碍。
<hr id="nIy6s" class="ne-hr">
## 1. 协议的三要素（核心逻辑）

要理解协议到底规定了什么，可以看这三个维度：


- **语法（Syntax）**：规定“怎么说”。定义数据的格式、编码和信号电平。例如：前 8 位是地址，中间是数据，最后是校验码。
- **语义（Semantics）**：规定“说什么”。定义每一段比特流代表的具体含义。例如：这部分代表请求连接，那部分代表传输完成。
- **时序（Timing）**：规定“什么时候说”。定义数据传输的顺序、速度匹配以及错误处理机制。
<hr id="Uzw5p" class="ne-hr">
## 2. 为什么协议要分层？

网络通信极其复杂（涉及电信号、路径选择、文件格式等），为了方便管理，工程师们把协议像剥洋葱一样分成了不同的**层（Layers）**。

每一层只负责一个特定的任务，并为上一层提供服务。这样做的好处是：如果你想把网线换成光纤（物理层改变），你并不需要重新写一遍浏览器代码（应用层）。

## 4. 一个典型的通信案例：刷网页

当你打开一个网页时，多个协议会“接力”工作：


- **DNS 协议**：先找到服务器的 IP。
- **TCP 协议**：与服务器打招呼（“你好，在吗？”“在的，开始发吧”）。
- **HTTP 协议**：发送请求（“我要看首页的图片”）。
- **IP 协议**：规划路径，把这些请求切成小包，穿过一个个路由器送到目的地。

### vpn

**VPN（Virtual Private Network，虚拟专用网络）** 是一种通过公用的互联网（Public Network）建立一条**加密、专用**的“隧道”，从而让你的设备能够安全地访问远端私有网络资源的技术。

### 1. VPN 的核心工作原理

VPN 主要通过以下三个步骤来保护你的通信：


- **隧道协议 (Tunneling)**：它把你的原始数据包封装在一个新的数据包里，就像给信件套上了一个不透明的厚信封。
- **加密 (Encryption)**：它对信封里的内容进行乱码化处理。即便黑客在公网上截获了你的数据，没有密钥也无法查看。
- **身份认证 (Authentication)**：确保只有经过授权的用户（通过账号密码或证书）才能进入这条隧道。

### 2. VPN 的主要用途

虽然现在很多人一提到 VPN 就会想到“绕过网络限制”，但在技术领域，它的初衷和核心用途非常广泛：


- **远程办公（企业最核心用途）**：员工在家里或出差时，通过 VPN 接入公司内网，访问只有在办公室才能使用的系统（如内部 OA、财务系统）。
- **公共 Wi-Fi 安全**：当你在咖啡馆使用免费 Wi-Fi 时，网络极易被监听。使用 VPN 可以加密你的所有流量，保护账号密码。
- **隐藏真实 IP**：你访问的目标网站只能看到 VPN 服务器的地址，无法看到你真实的地理位置和设备信息。
- **跨地域资源访问**：例如访问特定地区的学术数据库或流媒体内容。

### 4. 常见的 VPN 协议

不同的“隧道”使用的技术标准不同，性能和安全性也有差异：


- **IPsec**：最经典的协议，常用于站点到站点的连接，安全性极高。
- **SSL/TLS**：基于浏览器或轻量级客户端，非常灵活。
- **OpenVPN**：开源协议，平衡了速度和安全性，是目前主流的选择。
- **WireGuard**：最新的协议，代码量极简，速度非常快。

## 网络拓扑结构

### 1. 星型拓扑 (Star Topology)


- **结构**：所有节点都连接到一个中央设备（如交换机或集线器）。
- **特点**：管理最方便。一个分支坏了不影响整体，但如果**中心设备坏了，全网瘫痪**。
- **场景**：家用 Wi-Fi、办公室局域网。

### 2. 树型拓扑 (Tree Topology)


- **结构**：星型结构的分级扩展，像一棵倒挂的树，有根节点和分支节点。
- **特点**：层级分明，易于扩展和故障隔离。
- **场景**：大型校园网、企业级骨干网络。

### 3. 网状拓扑 (Mesh Topology)


- **结构**：节点之间多路径互连。分为“全网状”（两两相连）和“部分网状”。
- **特点**：**可靠性最高**。一条线路断了，数据会自动绕路。但成本高、配置复杂。
- **场景**：5G 基站连接、核心骨干网、家用 Mesh 组网。

### 4. 总线型拓扑 (Bus Topology)


- **结构**：所有设备共享一根主干电缆（总线）。
- **特点**：节省线缆，但主干线一旦断裂，整个网络立即失效。
- **场景**：早期的工业控制网络（目前已很少用于办公网络）。

### 5. 环型拓扑 (Ring Topology)


- **结构**：设备首尾相连形成一个闭合的环。
- **特点**：信号单向流动。结构简单，但任何一个节点故障都会导致闭环中断。
- **场景**：某些特定的工业自动化系统。

### 数据的大小

#### 1. 基础存储单位：比特与字节

**这是理解所有网络数据的基石：**


- **bit (比特/位)**：缩写为小写 **b**。它是计算机最小的信息单位，代表一个 0 或 1。
- **Byte (字节)**：缩写为大写 **B**。这是最常用的存储单位。
- **换算关系**：**$1\text{ Byte} = 8\text{ bits}$**。

**注意**：在网络协议头部分析（如查看 IP 包头）时，通常用 **bit**；但在下载文件查看大小时，通常用 **Byte**。
<hr id="K9fyP" class="ne-hr">
#### 2. 传输速率单位：宽带进率

当你办理“百兆宽带”时，这里的单位是 **bps (bits per second)**，即每秒传输的比特数。


- **Kbps**：10^3 bps =1,000 bps
- **Mbps**：10^6 bps = 1,000,000 bps（常说的“百兆”指 100 Mbps）
- **Gbps**：10^9  bps（千兆网络）
