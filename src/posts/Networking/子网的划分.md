子网划分（Subnetting）本质上是**从 IP 地址的主机部分“借用”几位作为网络部分**，从而将一个大的网络分割成若干个更小、更易于管理的小网络。

这种做法不仅能减少广播风暴，还能提高 IP 地址的利用率。

### 1. 核心概念：IP 地址的结构

在划分前，你需要理解 IP 地址由两部分组成：


- **网络地址 (Network ID)**：代表你所在的“街道”。
- **主机地址 (Host ID)**：代表街道上的“门牌号”。
<hr id="zfEvh" class="ne-hr">
### 2. 子网划分的步骤

划分过程通常遵循以下四个逻辑步骤：

#### 第一步：确定需求

你需要明确：是根据**需要多少个子网**来划，还是根据**每个子网需要多少台主机**来划？

#### 第二步：借位 (Borrowing Bits)

你会从主机位中“借”走 $n$ 位。


- **新增子网数** = $2^n$
- **剩余主机数** = $2^{(剩余位数)} - 2$ （减去 2 是因为要扣除网络地址和广播地址）

#### 第三步：计算新的子网掩码

将借走的位在掩码中从 0 变为 1。

**例子：** 一个 C 类地址 192.168.1.0/24，如果借走 2 位：


- 原来的掩码：255.255.255.0
- 新的掩码：255.255.255.192 (因为二进制 $11000000 = 192$)

#### 第四步：确定子网范围和块大小

**块大小 (Block Size) = 256 - 掩码最后一位的值。**

如果掩码是 192，块大小就是 256 - 192 = 64。这意味着子网将以 64 为间隔跳动：.0, .64, .128, .192。

### 快速记忆公式


- **子网数** = 2^n (n 为借位数)
- **可用主机数** = 2^h - 2 (h 为剩余主机位数)
- **CIDR 表示法**：/24 借 1 位变 /25，借 2 位变 /26，以此类推。
