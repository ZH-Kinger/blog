## ip地址是什么？

简单来说，**IP 地址**（Internet Protocol Address）就是联网设备在网络世界里的“**数字门牌号**”。
<hr id="JpAfS" class="ne-hr">
### 1. 核心定义

IP 地址是分配给网络中每个设备的一个**逻辑地址**。在 TCP/IP 协议栈中，它被用来在复杂的网络路径中精确定位一个设备，从而实现数据的发送和接收。

### 2. IP 地址的组成结构

目前主流使用的是 **IPv4**（由 32 位二进制数组成），为了方便人类阅读，通常写成“**点分十进制**”形式（例如：192.168.1.1）。它包含两个关键部分：


- **网络部分 (Network)**：标识设备所属的特定网络段。
- **主机部分 (Host)**：标识该网络段内的具体某台设备。
- **子网掩码 (Subnet Mask)**：用来区分哪些位是网络号，哪些位是主机号。
<hr id="WBWQp" class="ne-hr">
### 3. IP 地址的主要分类

根据首个字节的数值范围，IP 地址被划分为不同的等级：


- **A 类** (1-126)：适用于超大型网络。
- **B 类** (128-191)：适用于中型网络。
- **C 类** (192-223)：最常见，适用于小型局域网。
- **D 类** (224-239)：组播地址。
- **E 类** (240-255)：保留用于科研实验。

### 4. 公网与私有地址的区别


- **私有 IP 地址**：用于企业或家庭内部局域网（如 192.168.x.x）。不同的局域网可以重复使用这些地址，但它们不能直接访问互联网。
- **公网 IP 地址**：全球唯一。由运营商分配，用于在广域网上进行通信。
<hr id="MSpYt" class="ne-hr">
### 5. IPv4 与 IPv6


- **IPv4**：地址数量有限（约 43 亿个），目前已接近枯竭。
- **IPv6**：为了解决地址不足，采用了 128 位长度。它能提供极其海量的地址（号称能为地球上每一粒沙子分配一个 IP），且安全性更高。
