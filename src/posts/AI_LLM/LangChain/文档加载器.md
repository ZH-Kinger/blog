# 文档加载器

在 LangChain 的 RAG（检索增强生成）架构中，**文档加载器（Document Loaders）** 是整个流水线的“入口”。它的任务只有一个：**把各种格式的非结构化数据（PDF、Word、网页、数据库、代码）转换成 LangChain 统一识别的 `Document` 对象。**

无论原始文件是什么样，经过加载器后，都会变成一个包含 `page_content`（文本内容）和 `metadata`（元数据，如文件名、页码）的标准对象。

------

## 1. 常见的文档加载器分类

根据你的 AIOps 项目需求，你可能会用到以下几类：

#### ① 文件类（最常用）

- **`TextLoader`**: 加载纯文本文件（`.txt`, `.md`）。
- **`PyPDFLoader`**: 解析 PDF 格式的运维手册。它很强大，能按页拆分并保留页码信息。
- **`UnstructuredExcelLoader`**: 处理表格里的资产清单或故障记录。

#### ② 目录类（你正在用的）

- **`DirectoryLoader`**: **这是你的核心工具。** 它能扫描整个文件夹，配合 `glob="**/*.txt"` 可以递归加载所有子目录下的文件。它其实是一个“包装器”，内部可以调用其他的 Loader。

#### ③ 网络与 API 类

- **`WebBaseLoader`**: 抓取网页内容（比如 K8s 官方文档的 URL）。
- **`GitLoader`**: 直接从 GitHub 仓库下载代码或文档。

------

## 2. Document 对象长什么样？

了解加载器的输出，才能写好后面的处理逻辑。一个 `Document` 对象包含两个部分：

- **`page_content`**: 字符串，文件的实际文字。
- **`metadata`**: 字典，包含来源信息。例如 `{"source": "data/k8s.txt", "line": 10}`。

> **ZH-Kinger 笔记**：元数据非常重要！在 AIOps 中，如果 AI 给出了一个修复建议，你可以通过 `metadata` 告诉用户：“这个建议参考自《K8s 排障手册》第 45 页”。

------

## 3. 实战：如何高效使用加载器？

在你的 `ingest.py` 中，你已经用到了 `DirectoryLoader`。这里有几个高级技巧：

Python

```
from langchain_community.document_loaders import DirectoryLoader, TextLoader

# 高级用法：为不同后缀名指定不同的加载逻辑
loader = DirectoryLoader(
    './data',
    glob="**/*", # 扫描所有文件
    loader_cls=TextLoader, # 默认用 TextLoader
    loader_kwargs={'encoding': 'utf-8'}, # 解决 Windows 乱码的关键
    show_progress=True # 显示进度条，文件多时很有用
)
docs = loader.load()
```

------

## 4. 加载器的“三步走”工作流

加载器通常不是孤立存在的，它和 **Text Splitter（切分器）** 是好搭档：

1. **Load（加载）**: 把 100MB 的文档全读进内存，变成一个巨大的 `Document`。
2. **Split（切分）**: 因为 LLM 吞不下这么长的东西，需要用 `RecursiveCharacterTextSplitter` 把它切成 500 字一段的小块。
3. **Embed（向量化）**: 把小块变成向量存入 Chroma。

------

## 避坑指南

- **内存溢出**：如果你有几万个文件，不要一次性 `.load()`，可以使用 `.lazy_load()` 迭代器模式，边读边处理，节省内存。
- **编码问题**：在 Windows 上处理中文文档，**务必**在 `loader_kwargs` 里加上 `{'encoding': 'utf-8'}`，否则你会看到满屏幕的 ``。
- **依赖缺失**：很多 Loader 需要额外安装库（比如 `pip install pypdf` 或 `pip install unstructured`），报错时看清楚提示即可。

------

## 总结

**加载器 = 数据的翻译官。** 它屏蔽了底层文件格式的复杂性，让你后续的 `rag_chain` 只需要处理标准的 `Document` 对象。
